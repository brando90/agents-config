## Findings

1. **MAJOR — `scripts/deploy_cc.sh:161` (`is_agent`), from stage 1's `2c90dfb`. FIXED in `4af7377`.**
   Two defects, both refusing a healthy worker (the mirror image of the false success stage 1 was fixing).
   (a) The whole `ps` command line went through `shlex.split`; `ps` prints argv joined by spaces and quotes
   nothing, so an agent whose own prompt contains an apostrophe raises `ValueError: No closing quotation`,
   which the caller turns into "not an agent". Proven live: `shlex.split` on this very session's command
   line (pid 3612243, 12587 chars) raises. Now `command.split()`.
   (b) The executable allow-list `{wrapper, claude, claude.exe}` rejects `claude-pinned`, the private
   per-node copy of the binary Trigger Rule 46 tells every worker to run from. Nine such processes were
   running on skampere2 during this review. Now accepts the family name plus a separated suffix;
   `claudette` / `codexicon` still rejected, and the registry-pid, tmux-session, ancestry, non-zombie and
   start-time conjuncts are unchanged.
   *Verification:* `bash -n` 0; the embedded identity check against this session's own live registry entry
   and real `ps` went 1 → 0 (`d137fe65 pid 3612243`) and still returns 1 for a wrong tmux name; live
   end-to-end on real tmux: alive worker → exit 0, worker that exits → exit 1; new test
   `test_identity_accepts_pinned_copies_and_quoted_prompts` fails pre-fix (`1 != 0`), passes after;
   `python3 scripts/test_dispatch_scripts.py` 13 tests, exit 0.

2. **MAJOR — `scripts/agent_board.py:291` (`AGENT_RE`) and `:915` (`CODEX_RE`). FIXED in `2d927d5`.**
   `claude_registry()` counts a registry entry as a live process only when `AGENT_RE` matches the command
   line, and the pattern `(^|/)(claude|codex)(\s|$)|Claude Code` misses `claude-pinned` and the packaged
   Node entrypoint. Such a session gets `proc=False`, and when its entrypoint reads interactive it lands in
   `--resume-dead`'s list, where `all` types `clauded --resume <id>` into a new window — a second live
   process on one transcript, the exact outcome `8da03bf`'s liveness guard exists to prevent. The five
   pinned processes with registry entries on this node escape the em dash only because their prompts happen
   to contain the literal string "Claude Code", the regex's other alternative. Both patterns now accept a
   `-`/`_`-separated suffix and the packaged path; `.` is deliberately not a separator, because these are
   searched against a whole command line and `vim /tmp/claude.md` must not read as a running agent.
   *Verification:* `py_compile` 0; new `AgentBinaryTests` drives the real `claude_registry()` with a
   synthetic registry entry and process table — 2 of 3 fail pre-fix, all pass after; suites after the
   change: resume 22, serve 5, dispatch 13, slides 17, all exit 0.
